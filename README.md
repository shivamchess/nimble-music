# Nimble — Native Mobile Music Experience

Nimble is an open-source, ultra-clean native music player and downloader built with **Flutter**, designed around zen minimalism, paper-white aesthetic, and offline synced lyrics.

---

## 🎨 Visual Identity
- **Nimble Light (Default)**: Soft warm off-white canvas (`#F5F5F7`), white cards, and deep charcoal `#161618` controls.
- **Obsidian Dark**: Pure OLED pitch black mode.
- **Warm Dusk**: Sepia/linen tone.

---

## 🚀 How to Run & Build

### 1. Prerequisites
- Flutter SDK 3.0+ installed and on PATH (`flutter --version`)
- Android Studio / VS Code with Flutter extensions

### 2. Install Dependencies
```bash
cd nimble_mobile
flutter pub get
```

### 3. Run on Emulator or Physical Device
```bash
# Run on connected Android / iOS device
flutter run

# Or build release APK for Android
flutter build apk --release
```

The APK will be generated at `build/app/outputs/flutter-apk/app-release.apk`.
